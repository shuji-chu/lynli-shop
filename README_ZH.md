# 微澜 LYNLI (lynli-shop) 项目说明

## 一句话总结
本项目是一个用于销售情趣用品和成人玩具的轻量级电商网站前端项目，采用现代毛玻璃（Glassmorphism）UI 设计风格。

## 项目性质
- 当前阶段：前端静态页面（HTML + CSS + JS），属于 MVP（最小可行性产品）原型。
- 技术栈：原生 HTML5、CSS3、JavaScript。
- 数据存储：使用本地 `db.json` 作为模拟数据库。

## 目录结构
- `index.html`：商城核心页面，包含商品展示、购物车、结算等前端 UI 与交互逻辑。
- `db.json`：商品数据文件，包含商品列表（名称、价格、库存、描述、图标）以及模拟的订单记录。
- `logo.png`：品牌 Logo（微澜 LYNLI）。

## 商品数据说明 (db.json)
当前包含 5 个示例商品，结构如下：
- `id`：商品唯一标识。
- `name`：商品名称。
- `price`：售价。
- `stock`：库存数量。
- `emoji`：商品展示图标。
- `desc`：商品卖点与描述。
